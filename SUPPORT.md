# Getting Support

Thanks for using Plainfile. This page explains where to go for each kind of question.

## Bug reports and feature requests

Open a [GitHub Issue](https://github.com/vucetica/plainfile/issues/new/choose). Please search the existing issues first, because someone may already have reported the same thing.

## Questions, ideas and general discussion

Use [GitHub Discussions](https://github.com/vucetica/plainfile/discussions). Discussions work better than issues for "how do I..." questions, ideas, and anything open-ended.

## Security vulnerabilities

Please **do not** open a public issue. See [SECURITY.md](SECURITY.md) for the private reporting process.

## Mac App Store installation issues

Plainfile is free, so there is nothing to bill or refund. Problems with the App Store itself, such as downloads that do not start or account issues, are handled by Apple. Use [Apple Support](https://support.apple.com/) for those. For questions about the app itself, open a [Discussion](https://github.com/vucetica/plainfile/discussions).

## GitHub download (DMG) issues

The DMG on [GitHub Releases](https://github.com/vucetica/plainfile/releases/latest) is signed with a Developer ID and notarized by Apple, so macOS should open it without warnings. Open the DMG and drag Plainfile into the Applications folder. If macOS still blocks the app, or the download looks damaged, open a [Discussion](https://github.com/vucetica/plainfile/discussions) and include your macOS version and the exact message you see.

## What is not supported

Plainfile is a free app that is maintained in spare time. There is no guaranteed response time and no email support. Not every feature request will be accepted, but every request gets read.
