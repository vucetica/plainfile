## Description (max 4000 characters, 2393 used)
```
Plainfile is a free, native macOS editor for plain text, source code, Markdown and CSV files. It opens each kind of file in the view that suits it, and it always saves the file as plain text, so your files keep working in every other app. There are no in-app purchases and no subscriptions.

TEXT AND CODE
• Syntax highlighting for more than 30 languages and formats, including Swift, C, C++, C#, Java, Kotlin, Go, Rust, JavaScript, TypeScript, Python, Ruby, PHP, shell scripts, SQL, HTML, CSS, JSON, YAML and TOML
• The language is detected from the file name or the first line, and you can change it from the status bar
• Line numbers, word wrap, current line highlight and auto-indent
• Spaces or tabs, with the tab width you choose
• Find and Replace, Undo and spell checking

MARKDOWN
• Markdown files open in a rich text view that shows headings, bold, italic, links, images, lists, task lists, quotes, code blocks and tables
• Format text with familiar shortcuts, such as Command-B for bold and Command-K for a link
• Switch to the Markdown source at any time with Command-Shift-M
• Changes made in either view are saved as clean Markdown

CSV AND TABLES
• CSV and tab-delimited files open in a fast table that stays responsive with large files
• Click a column header to sort, and numbers sort as numbers
• Type in the search field to filter the rows
• Edit cells in place, add, duplicate and delete rows, and add, rename and delete columns
• Choose the delimiter and turn the header row on or off from the status bar

NATIVE AND PRIVATE
• Built with Swift, SwiftUI and AppKit for Apple silicon
• All your documents open as tabs in one window
• Autosave, versions, Open Recent and rename work like every other Mac app
• A status bar shows lines, characters, words, and the cursor's line and column
• Detects UTF-8, UTF-16, Latin-1 and Windows-1252 text, and keeps your LF, CRLF or CR line endings
• The window opens at the size and position you last used
• Plainfile has no network access, no account, no analytics and no tracking. It only opens the files you choose, and your files stay on your Mac
• Plainfile is open source under the MIT License

To try every mode, choose Help > Open Sample Files.

Requires macOS 26 or later on a Mac with Apple silicon.

Terms of Use: https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
Privacy Policy: https://plainfile.app/privacy
```
